# Edge Companions

Free Windows companion apps for ABE's CORSAIR XENEON EDGE widgets. Each widget is sold separately on Elgato Marketplace; these apps let it do the work iCUE widgets can't do on their own.

| Widget | Companion | Download |
|---|---|---|
| DOT Windows | DOT Windows Companion 1.1.0 | [zip](https://github.com/abdullam09/Edge_Companions/releases/download/v1.1.0/DOT-Windows-Companion-1.1.0.zip) |
| DOT Audio | DOT Audio Companion 1.0.0 | [zip](https://github.com/abdullam09/Edge_Companions/releases/download/dot-audio-v1.0.0/DOT-Audio-Companion-1.0.0.zip) |
| DOT Calendar | DOT Calendar Companion 1.0.0 | [zip](https://github.com/abdullam09/Edge_Companions/releases/download/dot-calendar-v1.0.0/DOT-Calendar-Companion-1.0.0.zip) |
| Dots Network | Dots Network Helper 1.0.0 | [zip](https://github.com/abdullam09/Edge_Companions/releases/download/dots-network-v1.0.0/DotsNetworkHelper-1.0.0.zip) |
| EDGE / DOT 1.0.7 | EDGE / DOT Companion 1.0.7 (optional) | [zip](https://github.com/abdullam09/Edge_Companions/releases/download/edge-dot-v1.0.7/EDGE-DOT-Companion-1.0.7.zip) |

Unzip to a permanent folder and run the app. Setup guides are on each widget's page. All releases: [Releases](https://github.com/abdullam09/Edge_Companions/releases).

Requires Windows 10/11 (64-bit).
