# DOT Windows Companion

The Windows tray app for the **DOT Windows** widget on the CORSAIR XENEON EDGE.

**Download:** [latest release](https://github.com/abdullam09/dotWindows_Companion/releases/latest)

1. Unzip and run `DotWindowsCompanion.exe`.
2. Leave it running in the tray. It starts with Windows and serves the widget on `ws://localhost:39072`.

Requires Windows 10/11 (64-bit). No .NET install needed.
